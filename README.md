# Вавилонская Библиотека — standalone-версия на Rust + Tauri

Современная самостоятельная реализация
[Вавилонской библиотеки](https://libraryofbabel.info)
Хорхе Луиса Борхеса: десктопное приложение на **Rust** (движок) и **Tauri v2**
(интерфейс), оформленное палитрой **Catppuccin Mocha**.

## Что внутри

- **Движок на Rust** (`src-tauri/src/babel.rs`) — библиотека не хранится, она
  вычисляется. Каждая страница — обратимое отображение своего адреса.
- **Кириллица в алфавите.** 64 символа: `a-z`, `а-яё`, пробел, запятая, точка,
  `!`, `-`. Русский текст — полноправная часть библиотеки, а не транслитерация.
- **Адресация как у оригинала:** `имя-гекса-w2-s4-v16:12`
  (гекс → стена 1-4 → полка 1-5 → том 1-32 → страница 1-410).
- **Поиск** по произвольному фрагменту: текст встраивается в сгенерированную
  страницу, адрес вычисляется обратным преобразованием.
- **Поиск изображений.** Страница — это сетка 80×40, ровно 3200 символов.
  Картинка сжимается до такой сетки и квантуется в 64 цвета алфавита, а её
  страница находится обратным преобразованием: изображение оказывается
  «зашито» в библиотеку навсегда, по тому же закону, что и текст.
  Любую страницу можно отрисовать как цветную сетку и сохранить в PNG.
- **Архив изображений** — отдельный раздел, сделанный по образцу
  [babelia.libraryofbabel.info](https://babelia.libraryofbabel.info). Здесь
  вместо букв перебираются цвета: сетка 640×416 (266 240 пикселей), 12 бит на
  пиксель, 4096 цветов. Локация — целое число из 3 194 880 бит, записанное
  десятичной строкой (~961 755 цифр, как у оригинала). Изображение получается
  умножением локации на нечётную константу по модулю `2^3194880`, поэтому
  картинку можно вписать в архив навсегда — у неё появляется своя локация,
  по которой её всегда можно найти.
- **Колоскоп** — перестановщик цветов, как `coloroscopy.html` в архиве
  изображений. Обход всех 16 777 216 оттенков RGB: самый быстрый канал идёт
  пилообразно (0→255→0), средний и медленный считаются как разряды смешанной
  системы счисления. Шесть режимов — все перестановки трёх каналов. Порт
  побитово совпадает с оригинальным `js/Coloroscopy.js` (сверено на 7200 шагов
  во всех режимах).
- **Разделение секций.** В боковой панели три группы: «Текст» (читать,
  обзор, поиск, оглавление, закладки, о библиотеке) и «Изображения» (страница
  как картинка, архив картинок, колоскоп).
- **Закладки**, сохранение тома/страницы в файл, оглавление тома, копирование
  адреса и страницы в буфер.
- **Короткие имена файлов.** Имя гекса — это base-36 от 19200-битного числа,
  то есть до ~11 500 символов; в имя файла оно не идёт. Файл называется
  `abc12345-w2-s4-v16-1a2b3c4d.txt`, а сам адрес пишется первой строкой
  внутри файла, поэтому сохранённую страницу можно открыть обратно.

## Как устроена математика

Страница — это 19200-битное число `V` (3200 символов × 6 бит).

```
книга   B = H * 640 + offset        H — имя гекса как число в base-36
страница V = (B * S_p) mod 2^19200  S_p — нечётная константа
```

Умножение на нечётное число по модулю `2^k` — биекция, поэтому
`B = V * S_p⁻¹ mod 2^19200` восстанавливает книгу из содержимого.
Обратный элемент считается методом Ньютона (16 итераций).

Отсюда следуют свойства:

- адрес ↔ содержимое — взаимно однозначное соответствие;
- страница не может измениться: она всегда на своём месте;
- хранить нечего: том из 410 страниц считается за миллисекунды.

### Архив изображений

Тот же закон, но вместо символов — цвета:

```
сетка     640 × 416 = 266 240 пикселей
палитра   4096 цветов = 12 бит на пиксель (по 4 бита на R, G, B)
локация   V = (B * S_i) mod 2^3194880     S_i — нечётная константа
обратное  B = V * S_i⁻¹ mod 2^3194880
```

Два пикселя — ровно 3 байта, поэтому поток читается тройками байт без
битовых сдвигов. Локация выводится десятичной строкой (~961 755 цифр),
как в оригинальном `babelia.cgi`. Обратный множитель считается методом
Ньютона: `x ← x·(2 − a·x)`, число верных бит удваивается на каждом шаге.

## Сборка

Требуется Rust (stable), Node.js 18+, Visual Studio Build Tools 2022 с
MSVC, WebView2 Runtime.

```bash
npm install
npm run tauri dev      # разработка
npm run tauri build    # сборка NSIS/MSI
```

Если сборка идёт из Git Bash и `cargo` не видит MSVC-окружение, есть
helper:

```bash
source ./build-env.sh
```

Он идемпотентен и сбрасывает `INCLUDE`/`LIB` перед вызовом `cmd` — иначе
переменная упирается в лимит Windows (32 КБ) и окружение перестаёт
возвращаться. Каталог сборки можно переопределить через
`CARGO_TARGET_DIR`, если стандартный `target/` мешает антивирусу.

Если `vcvars64.bat` на машине не работает, `tools/dump-msvc-env.bat`
задаёт `INCLUDE`/`LIB`/`LIBPATH`/`PATH` напрямую из известной раскладки
MSVC 14.44.35207 и Windows SDK 10.0.26100.0: поправьте версии под свою
установку.

## Проверки

```bash
npm run build                    # типы + сборка фронтенда
cd src-tauri && cargo test --lib # 30 тестов движка
cd src-tauri && cargo fmt --check
cd src-tauri && cargo clippy --all-targets -- -D warnings
python tools/check_contrast.py   # контраст обеих тем
```

## Навигация

Отдельной категории «Действия» нет. Команда лежит внутри того раздела,
с которым она связана, поэтому её место видно сразу:

| Раздел | Команды |
|---|---|
| Читать | Открыть файл, Копировать текст, Сохранить страницу |
| Оглавление | Сохранить том |
| Страница как картинка | Сохранить как PNG |

«Случайная страница» стоит в топбаре как главное действие, поэтому в меню
она не повторяется. Команды нарисованы тише разделов: раздел это место,
команда это то, что можно сделать в этом месте. Команды, которым нужна
открытая страница, отключены, пока страницы нет.

## Тема

Две темы, переключатель в топбаре. Тёмная (Catppuccin Mocha) основная, светлая
(Catppuccin Latte) для яркого окружения. Тема задаётся атрибутом `data-theme`
на `<html>`, поэтому переключение мгновенное, а компоненты о теме ничего не
знают: они читают только CSS-переменные. Выбор сохраняется в `localStorage`
и переживает перезапуск.

Все пары обеих тем проверены скриптом `tools/check_contrast.py`: порог 4.5:1
для текста, 3:1 для границ и индикаторов.

## Правила оформления

Если вы правите интерфейс, прочитайте `DESIGN.md`: там палитра, шрифты и
принципы, принятые для этого проекта. `AGENTS.md` указывает набор правил
antislop из каталога `skills/` (ядро плюс отдельные файлы про цвет,
текст, доступность, узкие экраны и комментарии в коде). Это фильтр, а не
источник вдохновения: решение о том, как должен выглядеть продукт,
принимает `DESIGN.md`.

Проверка контраста запускается отдельно:

```bash
python tools/check_contrast.py
```

## Тесты

```bash
cd src-tauri && cargo test --lib
cd src-tauri && cargo run --release --example probe_color -- 0 1200
```

Проверяются: уникальность алфавита, обратимость кодировки байт↔текст,
обратимость адреса и содержимого, стабильность страницы, поиск кириллицы,
разбор адресов, обратимость локации архива изображений (пиксели → локация →
пиксели), десятичный формат локации, обратный множитель по модулю `2^k`,
последовательность обхода цветов против эталона из оригинального JS.

`probe_color` печатает последовательность цветов в формате оригинального
`js/Coloroscopy.js` — её можно сверить с оригиналом напрямую.

## Отличие от оригинала

Оригинал на libraryofbabel.info использует 29 символов (латиница + ` ,.`),
страницу в 3200 символов и хранит в базе «закладки» на хэшах. Здесь алфавит
расширен до 64 символов кириллицей, страница та же по геометрии, а хранение
заменено файлом `bookmarks.json` в каталоге данных приложения.
